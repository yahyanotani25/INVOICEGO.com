# Source Conflicts, Ambiguities, Missing Data and External Dependencies

Each item states the evidence, what InvoiceGO does, and what needs confirmation.
"Spec" = *Technical Specification for DI API v1.12*; "Manual" = *DI User Manual v1.5*.

## B. Calculations

| # | Ambiguity | InvoiceGO rule (documented in docs/CALCULATIONS.md) |
|---|---|---|
| B1 | Is `valueSalesExcludingST` before or after `discount`? Not specified. SN005/SN006 send discount 56.36 with ST computed on `valueSalesExcludingST`. | `valueSalesExcludingST = quantity × unitPrice − discount`. The discount is reported in `discount` for information and is **never subtracted again**. |
| B2 | `totalValues` = "Total Sales Value (Including Tax)", but most samples send `0`, and SN008=145, SN012=132, SN013=212 do not reconcile. | Auto mode computes `valueSalesExcludingST + salesTaxApplicable + furtherTax + extraTax + fedPayable`. Scenario templates keep their supplied values. Differences are shown, not overwritten. |
| B3 | `fixedNotifiedValueOrRetailPrice` ("Item Based"): SN008/SN027 use it as total retail value (ST = rate × value), but SN021/SN023 put the per-unit fixed rate in it. | Third Schedule: `retailPricePerUnit × quantity`. Fixed-per-unit and composite rates: the user enters it, and the template value is preserved. |
| B4 | Further tax is not defined by the spec. The demo applies a 4% preset to all unregistered buyers. | No universal rule. Further tax is entered per line, with an optional business-level helper that is **off by default**. |
| B5 | Withholding (error 0008): must be 0 or equal to sales tax. | This is checked locally as a warning. Gross invoice value and net receivable (gross − ST withheld) are shown separately. |
| B6 | Rounding is not specified. | Values are computed at full precision and rounded half-up to 2 decimals per line. Quantity has 4 decimals. |

## H. Missing data and external dependencies (cannot be completed in code)

1. **Per-business FBR tokens**: sandbox and production tokens are issued through IRIS/PRAL. No real token was available, so **no live sandbox submission has been performed** during development.
2. **Static outbound IP** of the production host must be whitelisted in IRIS (Manual §4.1.1). Deployment needs a fixed egress IP (see DEPLOYMENT.md).
3. **SMTP credentials** for verification/reset emails.
4. **DNS/TLS for invoicego.com**.
5. **Confirmation of the QR payload** (A7) and the extraTax empty semantics (A4).
6. **Exact API sale-type strings** should be refreshed from `transtypecode` with a live token (C2).
7. **Client reference videos** could not be reviewed (YouTube blocked the build environment). Nothing from them has been implemented.
8. **Future subscription scope** is deferred (see DEFERRED_SCOPE.md).
